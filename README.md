# Machine Learning Practice

A learning repository for building practical data-analysis and machine-learning foundations in Python.

## Current notebook: Titanic exploration

`titanic.ipynb` explores Seaborn's Titanic dataset with:

- Dataset inspection using `head`, `info`, and `describe`
- Missing-value checks
- Basic survival-rate calculations
- Grouped comparisons by sex and passenger class
- Introductory visualizations with Pandas, Seaborn, and Matplotlib

This notebook currently focuses on exploratory data analysis. It does **not** yet train or evaluate a predictive machine-learning model.

## Run locally

```bash
python -m venv .venv
python -m pip install jupyter pandas seaborn matplotlib
jupyter notebook
```

Open `titanic.ipynb` and run the cells in order.

## Learning goals

- Understand tabular datasets
- Ask questions with Pandas
- Visualize patterns responsibly
- Handle missing data
- Progress toward feature preparation, model training, and evaluation
